# Paper Figures

These web-sized illustrations come from the MV-Sign paper. They are presentation assets, not additional benchmark data or original source-video releases.

| Web asset | Paper figure source |
|---|---|
| `overview.webp` | `figure/title.png` |
| `curation.webp` | `figure/datapipe2.png` |
| `generation.webp` | `figure/generationpipe.png` |
| `motion_comparison.webp` | `figure/dataset_compare.png` |

The figures are resized to at most 2400 pixels wide and encoded as WebP for GitHub loading. Transparent backgrounds are composited on white so diagram labels remain visible in both light and dark GitHub themes. Their content is not redrawn or generated. Original figures remain in the paper source.

RGB examples retain the attribution and applicable terms of their source datasets; the repository does not grant additional rights to those materials.
